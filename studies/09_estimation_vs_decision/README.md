# 估计精度与决策质量

**Notebook**：[estimation_vs_decision.ipynb](estimation_vs_decision.ipynb)

本篇不是复现，而是由 01、07 两篇的结果引出的模拟研究。01 篇：条件化的 ES 预测在单资产上明显更准；
07 篇：到了组合层面，用 ES 代替波动率几乎没有增量，GARCH 条件化的改进在 25bp 成本下消失。
真实数据无法拆解这个落差，因为不知道真实分布。本篇在**真实分布已知**的模拟中回答：

1. 风险估计更准，决策是否一定更好？
2. 估计误差中的哪一部分会传到决策？
3. 答案是否取决于优化问题的形式（min ES 与 ES 平价）？
4. 动态环境中，条件化带来的风险下降与它带来的换手相比值多少？

## 判定：更准的风险估计不一定带来更好的决策。决定决策质量的是估计误差中改变组合排序的部分、优化问题对它的敏感程度，以及交易规则；在 07 篇的设定（500 日窗口、ES 平价）下，非参数 ES 很难胜过协方差插件

## 设定

- **资产与 DGP**：6 个资产，波动率与相关结构仿照 07 篇（沪深300、中证500、标普500、国债、黄金、原油）。
  三个 DGP 的**协方差完全相同**，只有尾部不同：
  - 高斯；
  - 多元 t(4)：椭圆、厚尾、有尾部相关；
  - 崩盘混合：每天 1% 的概率出现风险资产同跌、国债黄金上涨的联合冲击，之后线性变换回同一协方差；非椭圆。
    敏感性分析中把概率改为 0.3% 和 3%。
- **决策规则**：

| 决策问题 | 高斯插件（样本协方差） | 非参数（历史情景） | oracle |
|---|---|---|---|
| min ES，单资产上限 40% | MV | MinES-HS（Rockafellar–Uryasev） | 真实分布下求解 |
| ES 平价 | ERC | ESP-HS（= 07 篇 TRP-历史） | 真实分布下求解 |

- **评价**：决策质量全部用真实分布计算。min ES 类：决策后悔 = 真实 ES(ŵ)/真实 ES(w\*) − 1；
  平价类：真实 ES 贡献偏离 Σ|RC_i − 1/6|。估计质量：固定组合上 ES 估计的相对误差，
  拆成「水平」（等权组合）和「形状」（两个组合 ES 之比，水平偏差在比值中抵消）。
- **实验 A**：独立同分布、单期；T = 125…4000 日；每格 500 次重复（敏感性 300 次）。
- **实验 B**：GJR-GARCH(1,1) 波动率，资产年化夏普均为 0.3；窗口 500 日，每 21 日调仓、期间持有，
  规则与 07 篇相同，另加部分调整（η = 0.3）。每个 DGP 40 条 10 年路径。
  真实条件分布已知，所以每天都能算出持仓的真实条件 ES 与条件方差；期望夏普不受实现收益噪声影响。
- **实现**：真实 ES 在椭圆族用解析式 k·√(w'Σw)，崩盘混合用 200 万天固定样本（实验 B 为每条路径 5 万天）。
  min ES 的 oracle 在大样本上用 SLSQP（ES 在大样本上几乎光滑，梯度为尾部情景的平均损失），
  ES 平价的 oracle 用 Spinu 凸形式加 L-BFGS-B。各规则的求解器直接复用 `01_methods`（`min_variance`、`min_cvar`、
  `erc_weights`、`es_parity_weights`、`fhs_scenarios`）。

## 结果

### 实验 A：独立同分布（每格 500 次重复）

**min ES 的决策后悔（%）**：真实 ES(ŵ)/真实 ES(w\*) − 1

| T | 高斯：MV / MinES-HS | t(4)：MV / MinES-HS | 崩盘混合：MV / MinES-HS |
|---|---|---|---|
| 125 | **1.17** / 4.89 | **2.72** / 8.22 | **6.38** / 8.00 |
| 250 | **0.68** / 2.62 | **1.82** / 4.75 | 4.73 / 4.76 |
| 500 | **0.30** / 1.28 | **1.02** / 2.68 | 3.38 / **2.31** |
| 1000 | **0.16** / 0.70 | **0.62** / 1.47 | 2.65 / **1.16** |
| 4000 | **0.04** / 0.18 | **0.19** / 0.41 | 2.15 / **0.33** |
| 设定错误下限 | 0 | 0 | 1.89 |

**估计精度（t(4)，相对误差 RMSE %）**：水平 = 等权组合的 ES；形状 = 两个组合 ES 之比

| T | 水平：高斯 / HS | 形状：高斯 / HS | 决策后悔：MV / MinES-HS |
|---|---|---|---|
| 250 | 15.6 / **15.3** | **8.1** / 12.6 | **1.82** / 4.75 |
| 1000 | 12.3 / **7.8** | **4.6** / 6.3 | **0.62** / 1.47 |
| 4000 | 9.3 / **3.8** | **2.4** / 3.1 | **0.19** / 0.41 |

高斯插件对 ES 水平稳定低估约 9%，但这是常数倍数，在比值中抵消。在全部 18 个（DGP, T）组合中，
「形状 RMSE 谁更小」与「决策谁更好」一致（崩盘混合 T = 250 两者都几乎相等）；「水平 RMSE 谁更小」在 t(4) 的 5 个窗口中给出相反结论。

**ES 平价：真实 ES 贡献偏离 Σ|RC − 1/6|（ERC / ESP-HS）**

| T | 高斯 | t(4) | 崩盘混合（下限 0.147） |
|---|---|---|---|
| 250 | **0.088** / 0.189 | **0.152** / 0.265 | **0.211** / 0.277 |
| 500 | **0.061** / 0.135 | **0.115** / 0.188 | **0.176** / 0.194 |
| 1000 | **0.042** / 0.094 | **0.083** / 0.134 | 0.159 / **0.138** |
| 4000 | **0.022** / 0.046 | **0.044** / 0.068 | 0.150 / **0.072** |

**敏感性：崩盘强度**（每格 300 次重复）

| 崩盘日概率 | MV 下限 | ERC 下限 | MinES-HS 胜出的 T\* | ESP-HS 胜出的 T\* |
|---|---|---|---|---|
| 0.3%（每年约 0.7 天） | 0.23% | 0.041 | 4000 | > 4000 |
| 1%（每年约 2.4 天） | 1.89% | 0.147 | 500 | 1000 |
| 3%（每年约 7.3 天） | 5.51% | 0.375 | 125 | 250 |

### 实验 B：GJR-GARCH 动态环境（每个 DGP 40 条 10 年路径）

**预测**：等权组合下一日 ES 的 log 误差 RMSE（%）

| | 高斯-hist | HS-hist | 高斯-cond | HS-cond |
|---|---|---|---|---|
| 高斯 | 18.2 | 18.9 | **4.6** | 6.0 |
| t(4) | 24.0 | 24.6 | 15.1 | **13.2** |
| 崩盘混合 | 28.4 | 28.7 | 21.6 | **18.2** |

**决策**：平价类的年化单边换手与期望夏普（0 / 10 / 25 / 50bp）

| | 高斯：换手 · 夏普 | t(4)：换手 · 夏普 | 崩盘混合：换手 · 夏普 |
|---|---|---|---|
| ERC-hist | 13% · 0.607 / 0.601 / 0.592 / 0.577 | 13% · 0.690 / 0.683 / 0.673 / **0.656** | 13% · 0.656 / 0.650 / 0.641 / **0.626** |
| ERC-cond | 51% · **0.633** / 0.609 / 0.574 / 0.515 | 58% · **0.713** / 0.683 / 0.638 / 0.563 | 56% · **0.683** / 0.657 / 0.617 / 0.552 |
| ESP-cond | 53% · 0.630 / 0.606 / 0.569 / 0.508 | 61% · 0.709 / 0.678 / 0.631 / 0.553 | 55% · 0.679 / 0.651 / 0.610 / 0.540 |

（每列加粗为四个可实施规则中的最高值，不含 oracle。）崩盘混合下，ESP-cond 的真实条件 ES 比 ERC-cond 低 9%（8.86% 对 9.75%，t = −24），
期望夏普只低 0.004。

### 结论

1. **估计更准不等于决策更好，决定决策的是「形状」误差。** 高斯插件在 t(4) 下水平误差更大，形状误差更小，决策更好。
2. **尾部信息只有在改变排序时才有用，并且需要足够的样本。** 椭圆族中非参数规则在任何样本量下都更差；
   非椭圆（崩盘混合）时，高斯插件有不随样本消失的设定错误下限，非参数规则在 T ≥ 500（min ES）之后胜出。
3. **平价问题比最小化问题需要约 2 倍的数据。** 07 篇 500 日窗口的 TRP-历史与普通风险平价无差别，与此一致。
4. **条件化让预测准得多，但决策净收益在 10–15bp 成本时归零**，25bp 时转负，与 07 篇在真实数据上的结论方向一致。
5. **用 ES 代替波动率，改变的是尾部风险而不是夏普**：用夏普评价 TRP 会看不到它的作用。
6. **把交易规则改得保守，比把估计改得更准更有用**：部分调整在 25bp 时是所有规则中最好的，甚至好于逐月按真实分布求解的 oracle。
   单期 oracle 在有成本时不是最优决策，决策问题本身应包含成本。

## 后续方向

- 在 07 篇的真实数据上检验结论 5、6：用 ES 类指标而非夏普评价 TRP；加入部分调整与带换手惩罚的 ES 优化
  min ES(w) + λ‖w − w_{t−1}‖₁。
- 把「形状误差决定决策」形式化：对 min ES 与 ES 平价，推导决策后悔对估计误差的一阶展开，
  看水平分量是否在一般（非椭圆）情形下也恰好消去，以及平价问题为何对边际贡献的误差更敏感。
- 多期、含成本的决策问题：把条件化的收益与换手成本放进同一个目标，与 Elmachtoub、Lam 等关于
  先估计再优化与整合方法的比较联系起来。

## 与已有文献的关系

min-CVaR 对估计误差敏感是已知的：Lim, Shanthikumar & Vahn（2011, *Operations Research Letters* 39(3)）
称之为「coherent but fragile」，并指出尾部越厚越严重；Kondor, Pafka & Nagy（2007, *JBF* 31(5)）
比较了不同风险度量的噪声敏感性；Ciliberti, Kondor & Mézard（2007, *Quantitative Finance* 7(4)）
研究了 ES 优化在 N/T 上的可行性相变。更一般地，Elmachtoub & Grigas（2022, *Management Science*）
的 Smart「Predict, then Optimize」讨论了预测误差与决策误差的差别。

本篇的增量在于：(i) 用协方差匹配的 DGP 把「尾部信息」与「二阶矩」严格分开；
(ii) 把估计误差拆成水平与形状，说明前者对决策无影响；(iii) 对比 min ES 与 ES 平价两种形式，
解释 07 篇中「换成 ES 没有增量」的现象；(iv) 在动态环境中把条件化的风险收益与换手成本放在同一尺度上。
这些是模拟证据，不是定理；能否推广到更一般的设定，见局限。

## 局限

- 模拟结论依赖 DGP。三个 DGP 只覆盖了「椭圆厚尾」与「一种非椭圆联合崩盘」两类尾部结构；崩盘方向、相关结构都是设定的。
- 「形状」误差只用一对组合（w\*min 与等权）的 ES 比值来度量，是机制的示意，不是一般性的度量。
- min ES 类设了 40% 的单资产上限，平价类不设上限，两类问题的约束不同，跨类比较 ES 水平没有意义。
- 实验 B 的方差递推把新闻截断在 ±4σ，以免崩盘新息让 GJR 波动率爆炸（第一版有 2 条路径达到长期水平的 57 倍和 117 倍）；
  估计端用正态 QMLE 的 GJR，与真实 DGP 的递推形式相同（但不知道截断）。真实市场中的 GARCH 设定错误会更严重。
- 期望收益设为常数且各资产夏普相同，因此夏普的差异只来自风险配置与成本，不涉及收益预测。
- 部分调整的 η = 0.3 没有优化；结论是「存在比逐期重新求解更好的规则」，不是 η = 0.3 最优。
- 交易成本按成交额的固定基点计，不含冲击成本。
