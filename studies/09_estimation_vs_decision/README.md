# 估计精度与决策质量

**Notebook**：[estimation_vs_decision.ipynb](estimation_vs_decision.ipynb)

**理论附注**：[theory_es_ratio.md](theory_es_ratio.md)（椭圆族下 ES 比值的命题、证明与适用边界）

**偏差–方差分解**：[bias_variance.ipynb](bias_variance.ipynb)（水平与形状误差的偏差、方差与理论渐近值）

本篇不是复现，而是由 01、07 两篇的结果引出的模拟研究。01 篇：条件化的 ES 预测在单资产上明显更准；
07 篇：到了组合层面，用 ES 代替波动率几乎没有增量，GARCH 条件化的改进在 25bp 成本下消失。
真实数据无法拆解这个落差，因为不知道真实分布。本篇在**真实分布已知**的模拟中回答下面四个问题，再回到 07 篇的真实数据检验模拟给出的预测：

1. 风险估计更准，决策是否一定更好？
2. 估计误差中的哪一部分会传到决策？
3. 答案是否取决于优化问题的形式（min ES 与 ES 平价）？
4. 动态环境中，条件化带来的风险下降与它带来的换手相比值多少？

## 判定：更准的风险估计不一定带来更好的决策。决定决策质量的是估计误差中改变组合排序的部分、优化问题对它的敏感程度，以及交易规则；在 07 篇的设定（500 日窗口、ES 平价）下，非参数 ES 很难胜过协方差插件。真实数据支持这些结论的方向，其中「部分调整」的证据最强

## 设定

- **资产与 DGP**：6 个资产，波动率与相关结构仿照 07 篇（沪深300、中证500、标普500、国债、黄金、原油）。
  三个 DGP 的**协方差完全相同**，只有尾部不同：
  - 高斯；
  - 多元 t(4)：椭圆、厚尾、有尾部相关；
  - 崩盘混合：每天 1% 的概率出现风险资产同跌、国债黄金上涨的联合冲击，之后线性变换回同一协方差；非椭圆。
    敏感性分析中把概率改为 0.3% 和 3%。
- **决策规则**：

| 决策问题 | 高斯插件（样本协方差） | 非参数（历史情景） | oracle |
|---|---|---|---|
| min ES，单资产上限 40% | MV | MinES-HS（Rockafellar–Uryasev） | 真实分布下求解 |
| ES 平价 | ERC | ESP-HS（= 07 篇 TRP-历史） | 真实分布下求解 |

- **评价**：决策质量全部用真实分布计算。min ES 类：决策后悔 = 真实 ES(ŵ)/真实 ES(w\*) − 1；
  平价类：真实 ES 贡献偏离 Σ|RC_i − 1/6|。估计质量：固定组合上 ES 估计的相对误差，
  拆成「水平」（等权组合）和「形状」（两个组合 ES 之比，水平偏差在比值中抵消）。
- **实验 A**：独立同分布、单期；T = 125…4000 日；每格 500 次重复（敏感性 300 次）。
- **实验 B**：GJR-GARCH(1,1) 波动率，资产年化夏普均为 0.3；窗口 500 日，每 21 日调仓、期间持有，
  规则与 07 篇相同，另加部分调整（η = 0.3）。每个 DGP 40 条 10 年路径。
  真实条件分布已知，所以每天都能算出持仓的真实条件 ES 与条件方差；期望夏普不受实现收益噪声影响。
- **实验 C**：07 篇的真实数据（2007-07 至 2026-10，233 次月度调仓），同样的 8 个规则加两个部分调整规则，月度调仓、期间持有。
  η = 0.3 沿用实验 B，没有在真实数据上调参。差值用分块自助法（20 日一块）给出 95% 区间。
- **实现**：真实 ES 在椭圆族用解析式 k·√(w'Σw)，崩盘混合用 200 万天固定样本（实验 B 为每条路径 5 万天）。
  min ES 的 oracle 在大样本上用 SLSQP（ES 在大样本上几乎光滑，梯度为尾部情景的平均损失），
  ES 平价的 oracle 用 Spinu 凸形式加 L-BFGS-B。各规则的求解器直接复用 `01_methods`（`min_variance`、`min_cvar`、
  `erc_weights`、`es_parity_weights`、`fhs_scenarios`）。

### 补充：估计误差的偏差–方差分解（[bias_variance.ipynb](bias_variance.ipynb)）

实验 A 只报告了 RMSE。这里把 MSE 拆成偏差² 与方差，DGP 扩展到高斯、t(ν)（ν = 3, 4, 5, 8, 15）与崩盘混合，q ∈ {0.95, 0.975, 0.99}，
T = 125…4000，每格 5000 次重复。被估计的是两个固定组合（真实 Σ 下的 w\*min 与等权）的 ES 水平与 ES 比值；
崩盘混合下统一用椭圆族的 w\*min，所以这一行的数字与实验 A 不可直接对比。
每个估计量的渐近偏差与渐近方差由影响函数在 1000 万天样本上算出，作为理论基准。

**比值（形状）的偏差与标准差（q = 0.95，相对误差 %）**

| DGP | 高斯插件 偏差 / sd（T = 1000） | HS 偏差 / sd（T = 1000） | 高斯插件 T·Var：模拟（T = 4000）/ 理论 | HS T·Var：模拟 / 理论 |
|---|---|---|---|---|
| 高斯 | +0.06 / 2.11 | +0.13 / 3.81 | 0.44 / 0.45 | 1.44 / 1.49 |
| t(15) | +0.03 / 2.32 | +0.26 / 4.32 | 0.56 / 0.53 | 1.91 / 1.87 |
| t(8) | +0.05 / 2.60 | +0.13 / 4.76 | 0.67 / 0.67 | 2.34 / 2.32 |
| t(5) | +0.03 / 3.34 | +0.15 / 5.63 | 1.24 / 1.34 | 3.08 / 3.17 |
| t(4) | +0.17 / 4.85 | +0.25 / 6.14 | 3.19 / ∞ | 4.06 / 3.96 |
| t(3) | +0.50 / 10.68 | +0.31 / 7.82 | 13.6 / ∞ | 6.35 / 6.38 |
| 崩盘混合 | **+9.87** / 7.14 | +1.14 / 8.24 | 5.56 / 5.74 | 6.78 / 6.61 |

1. **分布误设的偏差在比值中消失，但只在椭圆族中。** 高斯插件的 ES 水平有 −3%（t(15)）到 −9%（t(4)）的偏差，
   与理论常数 k^N_q / k_q − 1 一致，T = 4000 时偏差² 占水平 MSE 的 85–94%（ν ≥ 4）；同一估计量的比值在所有椭圆 DGP 中，T ≥ 1000 时偏差都不超过 0.5%，
   偏差² 占比在所有格子里都低于 1%。崩盘混合下比值偏差约 +9%（q = 0.95）到 +59%（q = 0.99），不随样本消失。
2. **高斯插件在形状上的优势全部来自方差。** 椭圆族中两种比值估计量都几乎无偏；高斯插件的渐近方差只有 HS 的
   28–42%（q = 0.95）、18–25%（q = 0.975）、9–12%（q = 0.99）（高斯与 ν ≥ 5）。它不依赖 q，HS 的方差随 q 提高而迅速增大，所以 q 越高，高斯插件的优势越大。
3. **ν ≤ 4 时这个优势会随样本量消失。** 样本协方差需要四阶矩才有 √T 的正态极限。t(4)、t(3) 下高斯比值的 T·Var 随 T 持续上升
   （t(4)：1.4 → 3.2；t(3)：2.8 → 13.6），HS 的 T·Var 保持稳定。t(4) 下高斯插件仍然更好，但差距从 T = 125 的 10.6% 对 16.8% 缩小到 T = 4000 的 2.8% 对 3.2%；
   t(3) 下从 T = 1000 起 HS 更好（q = 0.95）。T ≥ 500 时方差对 T 的双对数斜率：t(3) −0.56，t(4) −0.75（√T 收敛对应 −1）。
   方向与「2 < ν < 4 时误差为 T^{−(1−2/ν)} 量级」的猜想一致（猜想的斜率为 −0.67；ν = 4 时为 −1 加对数修正），但重尾下的蒙特卡洛误差很大，还不能确认具体速度。
4. **非椭圆时，交叉点可以由偏差与方差预测。** MSE_G ≈ β² + V_G/T，MSE_HS ≈ V_HS/T，故 HS 在 T\* ≈ (V_HS − V_G)/β² 之后胜出。
   崩盘混合下 T\* 的理论值为 110（q = 0.95）、54（q = 0.975）、6（q = 0.99）；模拟中 HS 在 T = 250、125、125 时首次胜出
   （模拟网格从 125 开始；小样本下 HS 自身有 O(1/T) 的偏差，所以 q = 0.95 时的交叉点比理论值晚）。
5. **实验 A 中 t(4) 的高斯水平 RMSE 受少数极端样本影响。** 实验 A 每格 500 次重复，T = 1000 时高斯水平误差的 sd 为 8.3%（最大单次误差 127%）；
   这里 5000 次重复得到 5.6%。四阶矩不存在时样本方差的分布很重尾，500 次重复的 RMSE 不稳定。实验 A 关于「形状误差决定决策」的结论不受影响。

HS 的偏差是 O(1/T) 的有限样本偏差：水平低估（高斯 DGP 下 T = 125 时 −3.9%，T = 4000 时 −0.15%），比值略高估。

### 结论

1. **估计更准不等于决策更好，决定决策的是「形状」误差。** 高斯插件在 t(4) 下水平误差更大，形状误差更小，决策更好。
2. **尾部信息只有在改变排序时才有用，并且需要足够的样本。** 椭圆族中非参数规则在任何样本量下都更差；
   非椭圆（崩盘混合）时，高斯插件有不随样本消失的设定错误下限，非参数规则在 T ≥ 500（min ES）之后胜出。
3. **平价问题比最小化问题需要约 2 倍的数据。** 07 篇 500 日窗口的 TRP-历史与普通风险平价无差别，与此一致。
4. **条件化让预测准得多，但决策净收益在 10–15bp 成本时归零**，25bp 时转负，与 07 篇在真实数据上的结论方向一致。
5. **用 ES 代替波动率，改变的是尾部风险而不是夏普**：用夏普评价 TRP 会看不到它的作用。
6. **把交易规则改得保守，比把估计改得更准更有用**：部分调整在 25bp 时是所有规则中最好的，甚至好于逐月按真实分布求解的 oracle。
   单期 oracle 在有成本时不是最优决策，决策问题本身应包含成本。
7. **真实数据支持 4–6 的方向。** 条件化的净收益在 18–25bp 归零；ES 平价让事后 ES 贡献更平均、实现 ES 降低 5–7%，但夏普与 ES/波动之比都不变，
   也就是说它通过多配国债整体降低风险，而不是改变尾部形状；部分调整保留了条件化的全部毛收益，换手降到约四分之一，50bp 时显著优于完全调整。
   真实数据只有一条路径，多数差值不显著：这是方向上的一致，不是独立的证明。

## 后续方向

- 把部分调整换成有原则的规则：带换手惩罚的 ES 优化 min ES(w) + λ‖w − w_{t−1}‖₁，或按成本与预测误差推导最优步长 η（实验 C 用的是固定的 η = 0.3）。
- 用更多真实资产宇宙（如 07 篇之外的行业、因子组合）检验「ES 平价降低风险但不改变尾部形状」是否普遍成立。
- 把「形状误差决定决策」形式化：对 min ES 与 ES 平价，推导决策后悔对估计误差的一阶展开，
  看水平分量是否在一般（非椭圆）情形下也恰好消去，以及平价问题为何对边际贡献的误差更敏感。
- 多期、含成本的决策问题：把条件化的收益与换手成本放进同一个目标，与 Elmachtoub、Lam 等关于
  先估计再优化与整合方法的比较联系起来。

## 与已有文献的关系

min-CVaR 对估计误差敏感是已知的：Lim, Shanthikumar & Vahn（2011, *Operations Research Letters* 39(3)）
称之为「coherent but fragile」，并指出尾部越厚越严重；Kondor, Pafka & Nagy（2007, *JBF* 31(5)）
比较了不同风险度量的噪声敏感性；Ciliberti, Kondor & Mézard（2007, *Quantitative Finance* 7(4)）
研究了 ES 优化在 N/T 上的可行性相变。更一般地，Elmachtoub & Grigas（2022, *Management Science*）
的 Smart「Predict, then Optimize」讨论了预测误差与决策误差的差别。

本篇的增量在于：(i) 用协方差匹配的 DGP 把「尾部信息」与「二阶矩」严格分开；
(ii) 把估计误差拆成水平与形状，说明前者对决策无影响；(iii) 对比 min ES 与 ES 平价两种形式，
解释 07 篇中「换成 ES 没有增量」的现象；(iv) 在动态环境中把条件化的风险收益与换手成本放在同一尺度上。
其中 (ii) 在椭圆族中有证明（[理论附注](theory_es_ratio.md) 推论 2：水平误差不改变 min ES 与 ES 平价的解）；其余是模拟证据，不是定理；能否推广到更一般的设定，见局限。

## 局限

- 模拟结论依赖 DGP。三个 DGP 只覆盖了「椭圆厚尾」与「一种非椭圆联合崩盘」两类尾部结构；崩盘方向、相关结构都是设定的。
- 「形状」误差只用一对组合（w\*min 与等权）的 ES 比值来度量，是机制的示意，不是一般性的度量。
- min ES 类设了 40% 的单资产上限，平价类不设上限，两类问题的约束不同，跨类比较 ES 水平没有意义。
- 实验 B 的方差递推把新闻截断在 ±4σ，以免崩盘新息让 GJR 波动率爆炸（第一版有 2 条路径达到长期水平的 57 倍和 117 倍）；
  估计端用正态 QMLE 的 GJR，与真实 DGP 的递推形式相同（但不知道截断）。真实市场中的 GARCH 设定错误会更严重。
- 期望收益设为常数且各资产夏普相同，因此夏普的差异只来自风险配置与成本，不涉及收益预测。
- 部分调整的 η = 0.3 没有优化；结论是「存在比逐期重新求解更好的规则」，不是 η = 0.3 最优。
- 实验 C 只有一条历史路径，夏普差的区间很宽；事后 rc_err 是不光滑的统计量，其自助区间偏斜，只作参考。
- 交易成本按成交额的固定基点计，不含冲击成本。
