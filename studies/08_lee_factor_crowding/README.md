## 判定：v1 的统计结果能复现，但「拥挤预示崩盘」不成立

**版本说明**：作者在 2026-09 发布了 v3，标题改为
*Return-Decay Residuals and Tail-Risk Forecasting: Timing Artifacts, Conditional Inference, and Cross-Market Evidence*。
v3 自己指出 v1 把同期残差当成了预测，并撤回了「双曲线衰减拟合得好」的说法。
本研究按 v1 的方法独立复现，用自己的数据和代码检验 v1 的问题，没有依赖 v3 的结论；最终得到的结论与 v3 一致。

## v1 的做法与结论

- **数据**：Kenneth French 数据库，8 个美股因子，月度，1963–2024。
- **alpha 代理**：滚动 36 个月夏普。
- **衰减模型**：双曲线 α(t)=K/(1+λt)，与指数、线性模型比较。
  在 1995–2024 年的**正夏普观测**上拟合，动量的 R² 为 0.65，判断类因子（价值、盈利、投资）低于 0.10。
- **拥挤信号**：在扩展窗口（至少 120 个月）上拟合双曲线，残差 = 实际 − 预测，负残差视为拥挤。
- **尾部检验**：用 1980–2000 年定阈值：拥挤 = 残差低于训练期中位数，崩盘 = 收益低于训练期 10% 分位。
  在 2001–2024 年样本外比较两种状态下的崩盘概率。
- **结论**：拥挤时，反转因子的崩盘概率是不拥挤时的 1.65–1.84 倍；动量相反，只有 0.38 倍（p=0.006）。

**v1 没有说明、本研究自行决定的取法**：
- 时间 t 从 1995 年起算（单位：年）；
- 用非线性最小二乘拟合；
- 拥挤残差只用严格早于当月的数据拟合；
- 崩盘同时给出「当月」和「下月」两种口径；
- p 值用 Fisher 精确检验。

v1 的交易策略和 ETF 成交量分析都没有给出定义，**未复现**。

## 结论

| 问题 | 结论 |
|---|---|
| v1 表 2（双曲线拟合） | **能复现**：动量 0.64（原文 0.65）、长期反转 0.31（原文 0.30），8 个因子都对得上。但这依赖只用正夏普观测：改用全部观测后，动量降到 0.51。而且滚动窗口高度重叠，也会抬高 R² |
| v1 表 4（拥挤与崩盘） | 原文的比值与本复现的「下月」口径相近：短期反转 1.76（原文 1.84）、长期反转 1.38（原文 1.65）；「当月」口径更大，短期反转为 3.10 |
| 当月口径 | **时间错位**：t 月的滚动夏普包含 t 月收益，t 月大跌会同时把残差拉低。在纯随机数据上走同样的流程，当月比值的均值约为 1.8 |
| 下月口径 | 在纯随机数据上，下月比值的 95% 区间是 [0.34, 1.87]，**两个反转因子都落在区间内**，不能与运气区分 |
| 动量 0.38 倍 | **阈值失效**：拥挤分界是 1980–2000 年动量最强时的中位数。测试期 288 个月中，有 279 个月被判为拥挤，比值实际上是用 9 个「不拥挤」月算出来的 |
| 衰减模型有没有贡献 | **没有**：直接用滚动夏普作信号，得到的比值相近甚至更大 |
| 控制波动率之后 | 把 8 个因子合并做逻辑回归：拥挤残差对下月崩盘的系数为 −0.08（p=0.36），**没有预测力**；近期 12 个月波动率的系数为 +0.43（p<0.001） |

## 与其他研究的关系

结论和本项目其他几篇一致：有预测力的是近期波动率，也就是波动率聚集；
用更复杂的拥挤度、尾部相关或 ES 度量，在这之外拿不到可检验的增量。
时间错位的问题也和兴业那篇的黄金信号同类：信号用到了与被预测收益同期的信息。

## 局限

- 时间 t 的起点和拟合方法是推断出来的；表 2 能几乎完全复现，说明推断大体正确。
- 只检验了美股 8 个因子。v3 还做了欧洲、日本、亚太地区，本研究没有涉及。
