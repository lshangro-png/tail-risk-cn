# KDE 模拟配置：国泰君安递推式的检验与修正

**Notebook**：[kde_simulation.ipynb](kde_simulation.ipynb)

## 来源与定位

国泰君安数量化专题之一百零九《资产配置之步步为营：尾部风险控制与优化》（2018-03-12，陈奥林）。
原文全文只在需要登录的资料站里，**没有取得**，方法取自整理稿 4.2.2 节：

1. 对各资产的历史收益做高斯核密度估计（KDE），独立抽样得到 K；
2. 对历史协方差做 Cholesky 分解 Σ = AAᵀ，用递推式注入相关：X_i = Σ_{j<i} (K_j − μ_j)/A_jj · A_ij + K_i；
3. 用过去 120 个交易日作输入，模拟 1500 次，求风险度量最小的权重。

整理稿称这个递推式「保证模拟协方差与历史一致、边缘分布与原资产一致」。
本研究在已知答案的数据和真实数据上检验这一说法，并和两种能严格保留边缘分布的做法对比：
**高斯 Copula + KDE 分位数逆变换**，以及 **Iman-Conover 秩重排**。

**与原文的差异**：
- 原文的风险度量「期内风险 + 期末风险（基于回撤和达标概率）」在整理稿里没有定义。
  这里改用模拟的 20 日期末收益的 95% ES，所以**不复现原文的收益数字**（股债年化 7.06%、五资产年化 10.1%）。
- 五资产里的恒生、标普 500、黄金换成在 A 股交易时段收盘的 ETF，债券用中债综合财富指数，样本从 2014 年开始。

## 结论

| 问题 | 结论 |
|---|---|
| 递推式能否保持协方差和边缘分布 | **不能**。在已知答案的数据上，第 2、3 位资产的方差分别高估 33%、22%，峰度被明显稀释，KS 距离是正确方法的 4–5 倍 |
| 真实数据上影响多大 | **取决于资产间的相关性**。股债两资产相关约为 0，几乎没有影响；五资产中，恒生、标普 500 的方差分别高估 52%、37% |
| 有没有额外的副作用 | **结果依赖资产的排列顺序**。排第一的资产不受影响；把沪深 300 挪到最后，它的方差被高估 70% |
| 是否改变配置 | **会，但幅度有限**。与正确方法的权重差异约 9–10%，蒙特卡洛噪声本身约 6%；方向上系统性地多配排在第一位的资产（沪深 300 的平均权重：排第一时 23%，排最后时 13%） |
| 是否影响样本外表现 | **不显著**。四个风险资产 2014–2026 年的回测中，各方法超额夏普在 0.96–1.03 之间，差值的 95% 区间都包含 0 |
| 正确的做法 | 高斯 Copula + KDE 逆变换，或 Iman-Conover。两者都保持边缘分布（方差误差只有 KDE 带宽带来的几个百分点），而且与资产顺序无关 |

## 细节

**已知答案的数据**：人工构造三个偏态厚尾、两两相关的资产，各方法模拟 10 万次：

| | 方差误差（第 1/2/3 位） | 第 2 位资产峰度（真实 5.91） | KS 距离（第 2 位） |
|---|---|---|---|
| 国泰君安递推 | +4% / **+33%** / **+22%** | **3.53** | 0.092 |
| 高斯 Copula + KDE | +2% / +4% / +2% | 5.73 | 0.017 |
| Iman-Conover | +1% / +2% / +3% | 5.59 | 0.017 |

**样本外**（沪深300、恒生、标普500、黄金四个风险资产，每月调仓，2014-08 至 2026-10，不计成本）：

| | 年化收益 | 年化波动 | 超额夏普 | 最大回撤 |
|---|---|---|---|---|
| 递推（原顺序） | 12.51% | 10.89% | 0.97 | −16.0% |
| 递推（倒序） | 13.23% | 10.85% | 1.03 | −17.6% |
| 高斯 Copula + KDE | 12.81% | 10.85% | 1.00 | −16.2% |
| Iman-Conover | 12.47% | 10.89% | 0.96 | −16.3% |
| 历史最小 ES（不模拟） | 11.46% | 11.05% | 0.86 | −17.3% |
| 最小方差 | 12.34% | 10.11% | 1.02 | −16.0% |
| 等权 | 9.25% | 12.34% | 0.59 | −19.6% |

## 局限

- 递推式和风险度量都取自整理稿，没有核对原文。
- 只检验了一种风险度量（20 日期末 ES）；在更依赖尾部形状的度量下（例如更高的置信水平），
  递推式稀释峰度的影响可能更大。
- 各日独立抽样，没有刻画波动率聚集。三种方法都有这个局限。
